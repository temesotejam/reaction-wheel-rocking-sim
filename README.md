# reaction-wheel-rocking-sim

リアクションホイールを搭載した左右ロッキング機体を **2次元（正面 X-Z 断面）** に限定して、エネルギー制御の成立条件を調べるためのシミュレータです。

このリポジトリの目的は、制御則を最初から正しいものとして実装することではありません。先に運動方程式を数値積分し、その結果から

- リアクションホイール入力 `Q [mA·s]` が左右揺動へどれだけ残るか
- `Q -> ΔE_obs` が単一の写像として扱えるか
- 同じ `Q` でも入力時の状態（特にゼロクロス角速度）で結果が変わるか
- 目標ピーク角に必要なエネルギーをリアクションホイールで実現できる範囲があるか

を確認することです。

## Version 0.1 のモデル

状態は

```text
theta      : 機体ロール角 [rad]
omega      : 機体ロール角速度 [rad/s]
omega_w    : リアクションホイール絶対角速度 [rad/s]
```

です。

足裏は `semicircle-decay-sim` で確認した実形状 Model B を使います。

```text
R = 150 mm
a = 5 mm   (中央欠損の半幅)
x_outer = 45 mm
H = 120 mm (直立時重心高さ)
```

接触モードは

```text
0 < |theta| < asin(a/R)
    内側端点まわりの回転

asin(a/R) <= |theta| <= asin(x_outer/R)
    R=150 mm 円弧での転がり
```

です。

### 位置エネルギー

内側端点支点領域:

```text
Δh = H(cos|theta|-1) + a sin|theta|
```

円弧転がり領域:

```text
hC0 = sqrt(R^2-a^2)
d = hC0-H
Δh = R - d cos(theta) - H
```

```text
U(theta) = m g Δh(theta)
```

### 有効慣性

重心まわりロール慣性を `I_cg` として、転がりによる重心並進も運動エネルギーへ含めます。

内側端点支点領域:

```text
J(theta) = I_cg + m(H^2+a^2)
```

円弧転がり領域:

```text
J(theta) = I_cg + m(R^2+d^2-2 R d cos(theta))
```

したがって機体の左右運動は

```text
J(theta) theta_ddot
+ 0.5 J'(theta) theta_dot^2
+ dU/dtheta
+ c theta_dot
+ tau_c tanh(theta_dot/omega_eps)
= -tau_motor
```

を数値積分します。

リアクションホイールには逆向きではなくモータトルクそのものが作用するため、

```text
J_w omega_w_dot = tau_motor
```

です。

## Q の扱い

このシミュレータでは `Q` をエネルギーと同一視しません。

```text
Q = integral(I dt) [mA·s]
```

から、仮のモータトルク定数 `k_t` を介してトルク波形を作ります。

```text
tau_motor = k_t I
```

`k_t` は現在 **実機同定前のパラメータ** です。Version 0.1 の既定値を実機値とは解釈しないでください。

## ΔE_obs(sim)

入力効果は、同じ初期状態から

1. Qあり
2. Q=0

を同時にシミュレーションして、Q投入後の次ピークで

```text
ΔE_obs(sim) = E_next_peak(Q) - E_next_peak(Q=0)
```

と定義します。

これは「Qが機械エネルギーそのもの」という意味ではありません。同一状態からの反実仮想差です。

## 何を判定するか

### Q sweep

同じ入力状態で Q を変化させ、`Q -> ΔE_obs(sim)` の形を確認します。

### 初期振幅 sweep

同じ Q を 5, 7, 9, 12, 15 deg の自由揺動へ入れます。入力は最初のゼロクロスで行うため、主にゼロクロス角速度が変わります。

同じ Q で `ΔE_obs(sim)` が大きく変わる場合、Q単独の写像では不足し、少なくとも

```text
ΔE_obs = f(Q, state)
```

が必要です。

これは直ちにエネルギー制御が不可能という意味ではありません。**入力状態を含めれば制御可能か**を次に調べます。

## 現時点で意図的に入れていないもの

- 3次元運動
- 前後歩行
- 接触滑り
- 脚・フレームの弾性
- 中央の白色柔軟部材の支持力
- モータ電流立上り/立下り
- 実測した `k_t` / Q→トルク変換
- 左右非対称
- IMU推定誤差

まず理想化された2D系で、理論そのものの成立条件を切り分けます。
