既定値は過去実測へ寄せています：m=0.1997 kg、R=0.150 m、zG=0.120 m、Ieff≈0.00090 kg·m²、c≈0.00050 N·m·s/rad、Jw≈2.1e−5 kg·m²、RW実用上限≈1050 rpm。IeffはCAD慣性ではなく自由減衰周期に合わせた等価値です。

比較する入力方式 Direct one-shot: Qdirect = Qff(A₀→Aref), 最初のZCで1回だけ その後: Q=0（増幅制御なし） Repeated mode Afree,k+1 = F_s(Ak) ΔEreq = U_s(Aref) − U_s(Afree) Qff = argminQ |U_s(Afree + g_s Q) − U_s(Aref)| Qcmd = max(0, Qff + I_s) I_s ← I_s + KI(Aref − Aactual)

予測で目標以上ならQ=0（ブレーキなし）。Qに人工的な上限は置きません。代わりに、gの同定範囲外は外挿警告、RW回転数は物理制約として判定します。

START_KICK自体は、中央の二点接触からの離脱モデルに強く依存するため、この画面では「START_KICK後に得られた最初のピーク A₀」から本制御を検証します。START_KICKは別試験として追加します。

成立性を見る指標

モデル追従: 実ピークがArefへ収束するか。

gの妥当性: Qffだけで残る偏差をI項が吸収できるか。

Q指令: Qcmd = max(0, Qff + I_s)。人工的なQ上限では切りません。

モデル信頼性: 非ゼロQの実測支持域は0.454–1.197 mA·s。下側・上側どちらの外挿も明示します。

物理限界: RW回転数上限・足裏モデル限界など、実際の制約に当たった場合にのみ制御能力不足と判定します。
