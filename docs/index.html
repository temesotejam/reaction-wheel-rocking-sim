Continuous controller

毎回のゼロクロスで Eref − Enow を評価します。

電流・ホイールモデル
機体・数値計算
ゼロクロスでの現在の制御則 ΔE = Eref − Enow Qneed ≈ |ΔE|·1000 / (kt·|ωcross|)

不足なら加振、過剰なら制動。不感帯内なら入力しません。Qは上限でクリップします。

Synchronized state history

白い縦線が現在のアニメーション時刻。上から機体角度、エネルギー、電流、ホイール速度、ホイール角度です。

この画面で見るべき因果関係

1. ゼロクロスで ΔE need が評価される。

2. 必要なら I cmd が ±300 mA などへ変わる。

3. I actual は遅れて立ち上がり、OFF後も減衰する。

4. 実電流から τmotor が生じ、wheelの速度・角度が変化する。

5. 反力で機体の Enow が変わり、次のゼロクロスで再評価される。

ここで収束しない場合は「表示の問題」ではなく、制御則・kt/Jw・損失モデル・Q近似のどこが不足しているかを次に切り分けます。
